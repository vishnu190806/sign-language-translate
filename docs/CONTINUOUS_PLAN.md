# Continuous Sentence Program — ISL-only, any person, full spoken sentences

**Goal (supersedes word-accuracy targets as primary):** any person signs continuously → system speaks full English sentences. Acceptance: sentence-WER + any-person (signer-disjoint AND sentence-disjoint) eval; word top-1 retained as secondary. Voice: English (Piper). ASL dropped. No human recordings; all data from direct/CC-BY sources. Hardware: Acer Predator Helios Neo 16 (i9-14900HX, RTX 4070 8GB, 16GB RAM, 1TB NVMe) — all local.

## Phase A — Continuous decoding
- **A1 Baseline (hours):** sliding-window multi-head classifier + temperature + hysteresis peak-picking + NMS + blank/epenthesis class. Rationale: standard Day-1 baseline; raw argmax-over-windows insufficient (Rastgoo et al. 2024, https://arxiv.org/abs/2402.14720); transitions need epenthesis modeling (Yang–Sarkar–Loeding, TPAMI 2010, DOI 10.1109/TPAMI.2009.158); keypoint word-spotting precedent (Deb et al., ICCV-HANDS 2024, https://arxiv.org/abs/2412.09475). Value: demos + pseudo-gloss mining; expect insertions.
- **A2 CTC head (days):** freeze multi-head encoder → 1D-CNN stem (2× downsample) → 3–4-layer Conformer/BiLSTM → 263+blank + `torch.nn.CTCLoss` + VAC auxiliary losses (Min et al., ICCV 2021, https://arxiv.org/abs/2104.02330). CTC over encoder-decoder at low data (Camgöz et al., CVPR 2020, https://arxiv.org/abs/2003.13830); pose-native precedent (AutoSign, ICCV-MSLR 2025, https://arxiv.org/abs/2507.19840; CSLRConformer, https://arxiv.org/abs/2508.01791; STARK, https://arxiv.org/abs/2603.16163). Gloss-free CLIP methods explicitly excluded (RGB-bound: GFSLT-VLP, ICCV 2023; SignCL, NeurIPS 2024; CLIP-SLA 2025). Decode: CTC beam search + bigram LM, collapse repeats, drop blanks.

## Phase B — Continuous data, zero recordings
- **B1 ISL-CSLTR (CC-BY-4.0, direct):** 700 videos / 100 sentences / 6–7 signers with time boundaries + signer variants (Elakkiya, Mendeley 2021, DOI 10.17632/kcmpdxky7p.1, https://data.mendeley.com/datasets/kcmpdxky7p/1). Extract pose, slice word clips. ✅ DONE 2026-10-02: corpus unpacked/inventoried (101 sentences + gloss transcripts); landmarks extracted → `data/processed/isl-csltr/landmarks/` (290 sentence `.npz`) + `word_landmarks/` (395 word `.npz`), validated loadable.
- **B2 Forced-align bank:** ❌ PARKED 2026-10-03 (8th collapse): CTC seeds 1–3 (CE-init+penalty → 100%; no-penalty → 99.0%; random-init → 99.0%; `models/ctc_seed*/`) join 5 historical blank-collapses — isolated-trained features don't transfer to co-articulated sentences at this data volume, no init/penalty/vocab variant escapes it. Fallback: uniform slicing (measured 0.326 on 60-sentence pseudo-benchmark `results/pseudo_sentences.json`, documented weak) + B3 proceeds on isolated-bank stitching only. Benchmark + Viterbi scorer kept (`scripts/build_pseudo_sentences.py`, `scripts/align_viterbi.py`, `tests/test_pseudo_sentences.py`).
- **B2 Forced-align bank:** small-vocab CTC seed on 100 sentences → CTC-logit Viterbi segmentation (~93% boundary accuracy, Zuo EMNLP 2024 / Cui 2019; tooling: https://github.com/robizso/slt-datagen). Clean per-gloss clips with real co-articulation.
- **B3 Synthesis:** template/LLM novel gloss sentences (ISL order) from isolated banks (ISL-CSLTR + ISL500 + INCLUDE), multi-signer assignment, speed jitter, **no L2 boundary smoothing**, novel content required (Robotka 2026, https://arxiv.org/html/2606.11925v1; SignBT, Zhou 2021, https://ustc-slr.github.io/highlight_news/21-02-01-signbt/; Saunders "Signing at Scale", CVPR 2022, https://arxiv.org/abs/2203.15354). Pre-train on synthetic, fine-tune **only on real ISL-CSLTR**. ISLTranslate/iSign eval-only (NC licenses + gating). ✅ DONE 2026-10-03 (isolated-bank half): 200 novel sentences, 0 real overlap, bigram coverage 2.00× real, 16 signer sources, boundaries 20/20 exact (`data/processed/synthetic/`, `scripts/synth_continuous.py`, `tests/test_synth_continuous.py`). LLM-novel half pending.

## Phase C — Gloss sequence → fluent speech (offline, 8GB VRAM)
- **C1 Rules (~200 lines, deterministic fallback):** SOV→SVO, time/topic fronting kept + comma, WH-final→front + `?`, NEG-final→AUX negation, INDEX→pronouns, `FS(X)` passthrough, Q_POLAR/Q_WH/NEG flags (polar-Q is face-only). Grammar: Zeshan 2000/2003/2006 (https://clok.uclan.ac.uk/9661, http://edoc.mpg.de/304065); Aboh et al. 2005; Kulshreshtha 2020/2025; fingerspelling two-handed British alphabet (Raj, WSLP 2025, https://aclanthology.org/2025.wslp-main.6.pdf).
- **C2 Tiny-LLM polish:** Qwen2.5-1.5B / Llama-3.2-1B/3B Q4 (~1–3GB VRAM), temp 0, pinned lexicon, FS-copy rule; rule output as automatic fallback. Basis: WSLP-2025 scaling (13.06→22.7→29.9 BLEU), Gloss2Text LoRA (Müller, EMNLP 2024, https://aclanthology.org/2024.findings-emnlp.947.pdf), SignLLM frozen-LLM pattern (Gong 2024, https://arxiv.org/abs/2404.00925).
- **C3 Speech:** full-sentence Piper synthesis (punctuation → prosody; never isolated glosses). Consider `en_US-libritts_r-medium` for paragraph prosody.

## Phase D — Any-person acceptance
- **D1 Harness:** signer-disjoint + sentence-disjoint splits (Artiaga, EMNLP 2025, https://aclanthology.org/2025.findings-emnlp.997/; Alyami, ICCV-MSLR 2025); WER + del/ins/sub + per-signer mean±std + worst signer; dep-vs-indep gap; webcam-stranger holdout.
- **D2 Techniques:** pose-norm (have) → signer-removal disentanglement (Zuo & Mak 2022, https://arxiv.org/abs/2212.13023; Haque, ICCV 2025, https://arxiv.org/html/2508.09372) → SDDA-style aug without signer IDs (Fu, NAACL 2024, https://aclanthology.org/2024.findings-naacl.140/) → episodic TTA (SAME, ACL 2026). Isolated robustness partially transfers (Zuo, EMNLP 2024, https://aclanthology.org/2024.emnlp-main.619; SignFlow, IEEE 2025: 19% WER continuous ISL).

## Phase E — Live sentence demo
Streaming decode → boundary detection (pause + Q/NEG flags) → Phase C → Piper; keep overlay/TTS/auto-speak; add confidence display.

## Portal intelligence (2026-10-03, from `cs.rkmvu.ac.in/~isl` cards)
- **STARK (Patra & Samanta, arXiv:2603.16163):** unified spatio-temporal keypoint attention for *continuous* SLR, 70–80% fewer params at comparable performance. Directly relevant if CTC program revives (Phase A2) — keypoint-native, laptop-shaped, same group as FDMSE-ISL.
- **Isharah (Alyami et al., IEEE TMM 2026):** 30k continuous videos, 18 signers, gloss-annotated, **direct downloads incl. Pose Data** (`snalyami.github.io/Isharah_CSLR` + GitHub). Caveat: Saudi SL, not ISL — methodological value only (STARK-style transfer, multilingual-pretraining evidence per SignCorpus). Parked unless continuous program needs non-ISL gloss supervision.
- **Production cards (IJCAI 2026 gloss-driven, ICSCC 2025 continuous-from-isolated):** reverse direction (text→sign); second portal page `cs.rkmvu.ac.in/~isl/sl_gen`. Marginal for us — B3 synthesis is template/LLM-based, but their continuous-from-isolated method is worth one read before B3 design.
